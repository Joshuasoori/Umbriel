## Architecture
- **Umbriel AI** — public assistant and community layer
- **UMBR** — Base Mainnet utility token
- **Umbriel Map** — planned Bitcoin Ordinals land / identity layer
- **Umbriel Community** — Discord, Telegram, Reddit, LinkedIn and later X
- **Umbriel Wallet** — planned privacy-first non-custodial wallet

## Principles
1. Product first, token second.
2. No guaranteed returns, fake volume, fabricated users, wash trading or deceptive FOMO.
3. Wallet keys remain under user control.
4. Security is defensive: isolation, decoys, quarantine, rotation and recovery — no hack-back.
5. Public claims must match what is actually live.
