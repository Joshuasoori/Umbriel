# Umbriel Telegram Launch Pack

## Recommended public structure
- **Umbriel Announcements** — read-only official updates
- **Umbriel Community** — discussion
- **Umbriel Bot** — AI assistant / FAQ / project status

## Bot welcome message
Welcome to Umbriel.

I can help with:
- official UMBR contract information
- current project status
- Umbriel Map
- development updates
- community links
- security guidance

I will not promise token returns and I will never ask for your seed phrase or private key.
