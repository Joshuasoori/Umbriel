# Umbriel — Project One-Pager

## What is Umbriel?
Umbriel is an AI-first onchain infrastructure project.

It combines:
- a public AI assistant
- UMBR, a fixed-supply utility token on Base
- Umbriel Map, a planned Bitcoin Ordinals land/identity layer
- community infrastructure
- a future privacy-first non-custodial wallet

100,000,000 UMBR fixed supply.

## Security philosophy
Umbriel is non-custodial by design. User signing keys should remain under user control. Security uses zero-trust, isolation, rotation, quarantine, monitoring and defensive decoys rather than hack-back.

## Community philosophy
Build in public. Distinguish what is live from what is planned. Do not fake engagement, market activity, partnerships or returns.
